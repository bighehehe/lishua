立刷POS机不用了，不建议随手丢弃或长期放置不管。用户应确认设备是否已激活、是否绑定结算卡、是否还有流量费、是否需要解绑或停用，以及是否存在押金未处理问题。

---

不少用户办了POS机，用了一段时间后不需要了，就把机器放进抽屉。

直到某天发现扣了流量费，或者换机器时发现原设备还绑定着，才想起处理。

不用了，不代表所有关系自动结束。

## 问题分析

停用前要看机器状态。

如果未激活，重点是联系办理渠道确认是否可以退回，详细处理可以参考[立刷POS机办理后不想用了怎么办？未激活和已激活处理方式](/news/lishua-pos-buyongle)。

如果已激活，就要关注：

| 检查项 | 说明 |
| :--- | :--- |
| **设备是否绑定账号** | 账号与机器的关联状态 |
| **结算卡是否还在** | 账户信息是否遗留 |
| **是否有历史交易** | 记录是否需要保存 |
| **是否有押金未返** | 冻结金是否处理完 |
| **是否有流量费** | 后续是否继续扣费 |
| **是否需要解绑设备** | 换机或停用前确认 |
| **是否需要关闭服务** | 避免服务延续 |

押金规则可以看[立刷POS机有没有押金？押金怎么返？](/news/lishua-pos-yajin)，押金长期未返可参考[立刷POS机押金迟迟不返怎么办？](/news/lishua-pos-yajin-bufan)，流量费扣费规则可以看[立刷POS机流量费是什么？每年都会扣吗](/news/lishua-pos-liuliangfei)。

## 解决方案

停用前建议按步骤处理：

1.  登录APP查看设备状态；
2.  查询是否有未结算交易；
3.  确认押金或冻结金是否处理完；
4.  查看流量费扣费规则；
5.  联系办理渠道确认解绑或停用；
6.  保留停用沟通记录；
7.  不要随便转送他人使用。

找不到处理入口时，可以参考[立刷POS机售后找谁处理？](/news/lishua-pos-shouhou)。

## FAQ

**Q：不用了必须注销吗？**
要看设备和账户状态。已激活设备建议咨询解绑或停用方式。

**Q：不用机器还会扣流量费吗？**
要看服务规则，建议停用前确认。
