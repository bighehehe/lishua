立刷POS机押金迟迟不返，先不要只看"对方说会返"，而要核对是否满足达标条件、是否超过返还周期、交易量是否统计成功、返还账户是否正确，以及办理渠道是否能提供处理路径。

---

POS机押金问题，是用户和代理之间最容易产生争议的地方。

很多人办理时听到"押金会返"，但没有问清楚什么时候返、怎么返、刷多少返、不达标怎么办。

等到押金迟迟没返，才发现问题没有那么简单。

## 问题分析

押金不返，常见原因有以下几类：

| 原因 | 说明 |
| :--- | :--- |
| **未达标** | 没有刷满约定金额或笔数 |
| **未到周期** | 返还时间还没到 |
| **统计口径不同** | 用户以为达标，系统口径未达标 |
| **返还账户问题** | 银行卡或账户状态异常 |
| **渠道沟通不清** | 办理时未明确返还规则 |
| **政策理解错误** | 把"有机会返"理解成"一定返" |

办理时押金到底怎么约定，可以参考[立刷POS机有没有押金？押金怎么返？](/news/lishua-pos-yajin)；首刷环节的注意事项，可以看[立刷POS机首刷激活注意什么？](/news/lishua-pos-shoushua)。

## 解决方案

处理押金不返，建议按下面步骤：

1.  找到办理时关于押金的说明；
2.  确认冻结金额；
3.  核对达标条件；
4.  查看交易量是否符合；
5.  确认是否超过返还周期；
6.  检查返还账户是否正常；
7.  联系办理渠道提交处理；
8.  保留聊天记录和交易截图。

如果办理时没有留下任何规则记录，后续维权会困难很多。找不到处理入口时，可以看[立刷POS机售后找谁处理？](/news/lishua-pos-shouhou)；押金对年度总成本的影响，可以参考[立刷POS机一年使用成本多少？费率、流量费、押金一起算](/news/lishua-pos-year-cost)。

## FAQ

**Q：押金没返是不是一定被骗了？**
不一定，先核对是否达标和是否到返还时间。

**Q：押金返还看口头承诺吗？**
不建议只看口头承诺，最好保留文字规则或截图。
