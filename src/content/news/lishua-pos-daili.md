做立刷POS机代理，不只是发机器，更重要的是获客、激活、售后和客户维护。新手做代理前，要先理解嘉联支付与立刷产品背景、代理政策、分润规则、返现条件、售后责任和潜在风险。

---

很多新手看POS机代理，第一眼看到的是分润和返现。但真正做起来才知道，代理不是简单把机器送出去。

用户后续的激活、押金、费率、不到账、机器故障，都会回来找代理。

## 一、代理到底做什么

代理要做的事情包括：

*   找客户；
*   讲清产品和嘉联支付背景；
*   解释费率和押金；
*   协助注册激活；
*   处理不到账和交易失败；
*   跟进售后；
*   维护长期交易。

| 代理工作 | 具体内容 | 对应能力 |
| :--- | :--- | :--- |
| **获客** | 找到有收款需求的个人和小微商户 | 地推、渠道、沟通 |
| **讲背景** | 说清立刷产品与嘉联支付的支付资质 | 政策理解 |
| **讲费用** | 解释费率、押金、流量费和返还条件 | 费用透明 |
| **协助入网** | 帮用户完成注册、认证、绑卡、激活 | 流程操作 |
| **处理问题** | 不到账、交易失败、机器故障的跟进 | 售后处理 |
| **长期维护** | 保持交易稳定，处理费率变化沟通 | 客户维护 |

## 二、新手最容易忽略什么

新手常只看"返现多少"，忽略：

*   政策是否稳定；
*   分润是否按时结算；
*   激活奖励是否有条件；
*   用户投诉谁处理；
*   机器库存是否有压力；
*   费率变化怎么沟通。

这些问题在签约前没有问清楚，做起来之后都会变成自己的成本。

| 容易忽略的问题 | 签约前要确认什么 |
| :--- | :--- |
| **政策稳定性** | 上级政策是否会频繁调整 |
| **分润结算** | 分润怎么算、多久结一次、通过什么方式结算 |
| **激活奖励条件** | 返现是否有交易量、时间、达标要求 |
| **售后责任** | 用户不到账、投诉由谁负责处理 |
| **库存压力** | 机器拿货价、退换货规则、滞销怎么处理 |
| **费率沟通** | 费率调整时，由谁通知用户、怎么解释 |

## 三、解决方案

做代理前，建议先把政策拆开看：机器成本、激活奖励、分润比例、返现条件、结算周期、售后责任、风险处理。

一份政策至少要拆成七个部分来理解：

1.  机器成本：拿货价多少，有没有首批量要求；
2.  激活奖励：什么算激活，奖励怎么算，何时发放；
3.  分润比例：按交易量的哪部分计算，比例是否长期稳定；
4.  返现条件：有没有交易量或时间门槛，未达标怎么处理；
5.  结算周期：分润多久结算一次，通过什么平台结算；
6.  售后责任：用户问题由上级处理还是代理自己处理；
7.  风险处理：政策变化、费率调整、投诉纠纷如何应对。

把这些问题写在纸上，逐条向上级确认并留好凭证，再决定投入多少。

## 常见问题FAQ

**Q：没有行业经验可以做吗？**
可以了解，但要先学习政策和售后处理。代理的核心不是发机器，而是能把用户的问题处理掉。

**Q：代理最难的是什么？**
不是发机器，而是长期维护客户。交易量稳定才有稳定分润，客户流失等于前期投入白费。
