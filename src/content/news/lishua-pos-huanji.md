立刷POS机机器坏了，应先判断是电量、网络、系统、流量卡问题，还是设备硬件故障。确认需要换机时，要准备设备编号、绑定手机号、故障照片或视频，并联系办理渠道或官方客服按流程处理。

---

机器开不了机、连不上网、无法签到、刷卡失败，用户很容易认为"机器坏了"。

但换机前，先要判断问题到底是不是硬件故障。

## 问题分析

常见故障可以分成两类。

第一类是非硬件问题：

| 非硬件问题 | 硬件问题 |
| :--- | :--- |
| 没电 | 无法开机 |
| 网络差 | 充电无反应 |
| 流量卡到期 | 屏幕损坏 |
| 系统异常 | 键盘失灵 |
| 参数未更新 | 读卡模块异常 |
| APP绑定问题 | 设备摔坏或进水 |

非硬件问题通常不需要换机，售后处理即可。比如流量卡引起的联网失败，可以先看[立刷POS机流量卡到期怎么办？](/news/lishua-pos-liuliangka-daoqi)。

## 解决方案

换机前建议先做基础排查：

1.  充电30分钟后再开机；
2.  更换充电线和插头；
3.  重启设备；
4.  检查网络和流量卡；
5.  截图或拍摄故障提示；
6.  联系服务商确认是否需要换机；
7.  换机前确认原设备是否解绑；
8.  新设备绑定后做小额测试。

确认需要换机时，准备好设备编号、绑定手机号和故障照片或视频，再联系服务商或官方客服，处理路径可以参考[立刷POS机售后找谁处理？](/news/lishua-pos-shouhou)。如果换机是因为不想再使用旧设备，也可以看[立刷POS机办理后不想用了怎么办？](/news/lishua-pos-buyongle)。

## FAQ

**Q：机器坏了可以直接换新吗？**
要看故障原因、保修规则和办理渠道政策。

**Q：换机后原来的交易记录还有吗？**
交易记录通常与账号或系统有关，具体以APP显示为准。
