立刷POS机到账金额比刷卡金额少，通常是因为扣除了交易手续费，也可能涉及秒到费、流量费、服务费或其他费用。用户应先核对交易金额、到账金额、交易方式、费率和扣费明细，再判断是否异常。

---

很多用户刷卡后发现："刷了1万元，到账不是1万元。"

这其实是POS机使用中的正常疑问。

POS机交易通常会扣手续费，所以到账金额少于刷卡金额并不一定异常。关键是少了多少，扣费是否符合之前确认的规则。

## 问题分析

到账金额变少，常见原因有以下几种：

| 原因 | 说明 |
| :--- | :--- |
| **交易手续费** | 刷卡或扫码按费率扣费，是最常见原因 |
| **秒到费** | 选择快速到账时，可能单笔加收费用 |
| **流量费刚好扣除** | 部分机器在特定时间或交易后扣流量费，容易被误认为手续费变高 |
| **费率变化** | 后续费率调整后，单笔到手金额也会变化 |
| **交易方式不同** | 刷卡、扫码、云闪付费率不同，不能混在一起比较 |

各项费率的区别，可以参考[立刷POS机费率是多少？刷卡、扫码、云闪付怎么区分](/news/lishua-pos-feilv)。想知道具体扣了多少，可以看[立刷POS机刷卡1万元扣多少钱？手续费怎么算](/news/lishua-pos-10000-fee)。

## 解决方案

可以按这个公式初步核算：

```
实际扣费 = 刷卡金额 - 到账金额
实际费率 = 实际扣费 ÷ 刷卡金额
```

算出实际费率后，再逐项核对：

1.  这笔是刷卡还是扫码；
2.  当前对应费率是多少；
3.  是否有秒到费；
4.  是否扣了流量费；
5.  是否有费率调整通知；
6.  APP交易明细是否显示费用。

举个简单例子：刷卡1万元，到账9940元，实际扣费60元，实际费率0.6%，与约定费率一致，就属于正常扣费。

如果核算结果明显不一致，再联系服务商确认。流量费是否被扣除，可以看[立刷POS机流量费是什么？每年都会扣吗](/news/lishua-pos-liuliangfei)；费率是否被上调，可以看[立刷POS机费率突然上涨怎么办？先确认这几件事](/news/lishua-pos-feilv-shangzhang)。

## FAQ

**Q：到账金额少是不是机器有问题？**
不一定，先看是否扣除了手续费或其他费用，再判断是否异常。

**Q：手续费怎么看？**
可以通过交易金额、到账金额和APP明细核算，也可以让服务人员协助确认。
