很多用户问"嘉联支付有没有支付牌照"，真正关心的是：立刷POS机刷卡后资金是否安全，机器是不是正规渠道，后续不到账能不能处理。

这个问题不能只看一句"有牌照"或"正规"，还要看具体办理和使用过程。

## 问题分析

公开资料可以作为判断基础，但用户最终使用的是一台具体机器、一套具体政策、一个具体办理渠道。

正规性判断至少包括五个方面：

| 判断维度 | 用户要看什么 |
| :--- | :--- |
| **支付公司背景** | 是否能对应到嘉联支付相关信息 |
| **入网流程** | 资料是否真实规范 |
| **结算路径** | 资金是否结算到绑定账户 |
| **费用规则** | 费率、押金、流量费是否清楚 |
| **售后责任** | 不到账、故障、扣费谁处理 |

只看支付牌照，不看办理渠道，仍然可能遇到费用和售后争议。品牌与支付公司的关系，可以先看[立刷和嘉联支付是什么关系？](/news/lishua-jlpay-guanxi)；整体判断方法可以参考[立刷POS机正规吗？如何判断是否靠谱](/news/lishua-pos-zhenggui)。

## 解决方案

用户办理前可以这样问：

-   这台机器对应的产品和入网方式是什么？
-   交易记录在哪里查？
-   结算到哪个账户？
-   费率、押金和流量费是多少？
-   出现不到账谁负责处理？
