立刷POS机售后联系不上时，先整理设备编号、交易记录、绑定手机号、办理沟通记录，再尝试联系原办理人员、上级服务商、APP内客服或官方渠道。办理前确认售后责任，可以减少后期被动。

---

POS机真正考验服务的，不是发货那一刻，而是出问题以后。

很多用户遇到不到账、押金不返、机器故障时，才发现原来的办理人员联系不上。

这时不要只着急，要先整理资料，再找正确路径处理。

## 问题分析

售后联系不上，常见原因有：

| 原因 | 说明 |
| :--- | :--- |
| **办理人员离职或换号** | 原联系方式失效 |
| **代理只负责发机** | 发机后不承担售后责任 |
| **未保留沟通记录** | 出问题时无据可查 |
| **机器已转手或资料不清** | 设备归属难以确认 |
| **需官方或上级处理** | 原代理层面解决不了 |

不同问题对应不同处理路径。不到账和交易异常，需要交易资料，可先按[立刷POS机刷卡不到账怎么办？先按这5步排查](/news/lishua-pos-budaozhang)自查；押金问题，需要办理政策记录，可参考[立刷POS机押金迟迟不返怎么办？](/news/lishua-pos-yajin-bufan)；设备故障，需要机器编号和故障证据，可看[立刷POS机机器坏了怎么换？](/news/lishua-pos-huanji)。

## 解决方案

建议按顺序处理：

1.  先找原办理人员；
2.  找当时的聊天记录、快递记录和政策说明；
3.  登录APP查看客服入口；
4.  准备设备编号和绑定手机号；
5.  整理交易截图或扣费记录；
6.  尝试通过官方或服务商渠道反馈；
7.  以后办理时保留固定售后联系人。

具体的售后分工和责任划分，可以参考[立刷POS机售后找谁处理？](/news/lishua-pos-shouhou)。

## FAQ

**Q：找不到代理是不是就没办法了？**
不一定，可以尝试通过APP或官方渠道寻找客服路径，但资料要准备完整。

**Q：办理前怎么避免售后失联？**
确认售后联系人、处理范围、客服电话或服务渠道，并保留记录。
